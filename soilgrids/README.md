## Soilgrids subset

Tests have been performed on soilgrids 5000m and soilgrids 1000m, see

https://files.isric.org/soilgrids/latest/data_aggregated/

Aggregated data is easier to test on, but they are not as fine-grained as the 250m version.

https://files.isric.org/soilgrids/latest/data/
